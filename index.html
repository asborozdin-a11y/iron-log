Как получить токен (одноразово, 2 минуты)
  1. GitHub → аватарка → Settings → внизу слева Developer settings.
  2. Fine-grained personal access tokens → Generate new token.
  3. Repository access: Only select repositories → выбери iron-log.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate token → скопируй и вставь в поле «ТОКЕН» выше.

Токен хранится только на этом устройстве и уходит только на api.github.com.
