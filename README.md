# IRON LOG

Дневник тренировок, замеров тела и питания в виде приложения для телефона (PWA). Работает без интернета, данные хранятся на устройстве. Без сборки и зависимостей: чистые HTML, CSS и JavaScript.

**Открыть:** https://asborozdin-a11y.github.io/iron-log/

## Возможности
- **Тренировки:** программа по дням, подходы с весом и повторами, таймер отдыха, журнал, рекорды, серия недель и цель недели.
- **Замеры тела:** форма в два столбца, разница с прошлым значением прямо при вводе, графики динамики, история.
- **Питание:** план КБЖУ и меню на день.
- **Профили** с PIN-кодом, четыре темы оформления, два набора программ.
- **Напоминание о замере:** уведомление со звуком, повтор (разово, ежедневно, через день, еженедельно, ежемесячно), экспорт в календарь.
- **Облачная копия** в личный репозиторий GitHub (по желанию).

## Установка на телефон
- **Android (Chrome):** меню ⋮ → «Установить приложение» или «Добавить на главный экран».
- **iPhone (Safari):** «Поделиться» → «На экран Домой». Уведомления на iPhone работают только у установленного приложения.

После выхода новой версии внизу появится плашка «Доступно обновление». В профиле видна текущая версия и есть кнопка «обновить приложение».

## Данные и приватность
Все записи лежат в памяти браузера на вашем устройстве. Облачная копия включается вручную: нужен токен GitHub (fine-grained) только с доступом к одному репозиторию данных. PIN защищает вход в приложение, но не шифрует данные.

## Уведомления
Приложение без сервера не может прислать уведомление, пока оно полностью закрыто. Напоминание приходит, когда приложение открыто или свёрнуто. Чтобы напомнило и при закрытом приложении, добавьте событие в календарь кнопкой «Добавить в календарь».

## Запуск на компьютере
Нужен локальный сервер (в режиме `file://` не работает офлайн-кеш):

```bash
python -m http.server 8765
```

Откройте `http://localhost:8765`.

## Структура
| Файл | Назначение |
|---|---|
| `index.html` | разметка экранов |
| `style.css` | темы и стили |
| `data.js` | программы тренировок и питание |
| `app.js` | ядро: профили, хранилище, навигация, облако, напоминания |
| `train.js` | тренировки и журнал |
| `measure.js` | замеры |
| `food.js` | питание |
| `sw.js` | офлайн-кеш и уведомления |

При изменении файлов из списка в `sw.js` поднимайте версию кеша `ironlog-vNN`, иначе у пользователей останется старая версия.
